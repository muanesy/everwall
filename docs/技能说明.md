# 技能说明

卡面上的描述来自 `game.js` 的 `SKILL_DESCS`，改描述只改那里。

## 测试开关

`src/game.js` 顶部：

```
const UNLOCK_ALL_SLOTS_FOR_TEST = true;
```

true 的时候，五个槽位（攻城、近防、支援、指挥、工事）默认全部解锁，方便逐个测试。测试完改回 false，槽位恢复成抽卡解锁。

## 五个槽位

| 槽位 | 位置 | 效果 | 节奏 |
| --- | --- | --- | --- |
| 攻城 | (4.5, 15) | 打僵尸最密的一群，半径 2.6，30 伤害 | 每 6 秒 |
| 近防 | (5.5, 4.5) | 打身边 3 单位内的僵尸，8 伤害 | 每 0.5 秒 |
| 支援 | (-4.5, 15) | 回复 1 个兵，时代越高越多 | 每 10 秒 |
| 指挥 | (0, 15) | 全队射速 +5%，时代越高越多 | 常驻 |
| 工事 | z=0，路障 | 挡僵尸、挨打、反击，5 级成长 | 碎了 10 秒重建 |

伤害和治疗每进一个时代 +25%。

## 效果类型

技能共用几套通用逻辑，正式特效由乙按 `docs/美术需求-槽位与技能.md` 替换：

- `aoe`：落点范围伤害
- `line`：横排伤害
- `slow`：全场减速
- `buff`：全队射速
- `heal`：回兵
- `pull`：把僵尸拉向一点
- `warp`：把僵尸送回屏幕顶端
- `sacrifice`：扣兵换全屏伤害
- `clear`：清空场上僵尸
- `upgradeSlot`：路障升级
