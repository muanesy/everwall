# 技能说明

卡面上的描述来自 `game.js` 的 `SKILL_DESCS`，改描述只改那里。这份文档写的是实际代码效果，卡面放不下的细节都记在这里。

## 测试模式

主界面有一个「测试模式」开关，打开后开始按钮变成「开始测试」。进游戏后屏幕左侧出现测试面板：

- 6 个时代按钮，点了立刻换时代和地图，不受波次影响
- 6 个槽位（攻城、近防、支援、指挥、召唤、工事），可以 +/- 调 1-5 级，面板上直接显示当前数值
- 30 个一次性技能按钮，点一下立刻释放，不受当前时代限制
- 「刷 20 只僵尸」「清空僵尸」；环境事件分成 6 个按钮（地震/陨石/恶劣天气/毒雾/熔岩/电磁），点哪个就直接触发哪个，不受当前地图限制；天气事件上方还有 6 个天气类型按钮（暴雨/浓雾/风暴/沙尘/强风/暴雪），先选类型再点「恶劣天气」；旧的「当前地图事件」按钮保留
- 手机上面板默认收起，点左上角「测试面板」展开成底部抽屉，最多占半屏、可上下滚动；电脑保持左侧常驻

测试模式里士兵不会掉血，僵尸也啃不动路障；炸药桶不生成、不触发；波次不再触发自动技能和升级面板。士兵子弹正常造成伤害，技能、槽位和路障反击也照常生效。测试模式会隐藏左侧技能栏，避免和测试面板重叠。

`src/game.js` 里不再有 `UNLOCK_ALL_SLOTS_FOR_TEST` 这个常量，正常进游戏时槽位全部锁定，靠地图结束的升级面板解锁和升级。

## 六个槽位

槽位有 1-5 级。时代决定科技家族，等级决定伤害、半径、间隔、回兵数和路障血量。完整数值见 `docs/槽位升级数值.md`。

下表是 1 级基准值，实际值还会乘时代倍率和欠级折扣。召唤槽的解锁项与升级项后现代起才进升级面板，星际起保底自动解锁。

| 槽位 | 位置 | 1 级基准 | 节奏 |
| --- | --- | --- | --- |
| 攻城 | (4.5, 15) | 打最密的一群，半径 2.6，30 伤害；炮弹飞行 0.5 秒，落地才结算 | 每 6 秒 |
| 近防 | (5.5, 4.5) | 打身边 3 单位内的僵尸，8 伤害 | 每 0.5 秒 |
| 支援 | (-4.5, 15) | 回复 1 个兵 | 每 10 秒 |
| 指挥 | (0, 15) | 标记场上血量最高的敌人，子弹打中它时伤害 +15%；每 3 秒换一次目标 | 常驻 |
| 召唤 | (-5.5, 4.5) | 制造友方僵尸，1 级只有盾尸（80 血 / 14 伤），预算 2 | 每 8 秒 |
| 工事 | z=0，路障 | 240 血、无反击、宽 4.2 | 碎了 10 秒重建 |

最终数值 = 基础值 × 时代倍率 × 等级倍率 × 欠级折扣。低于时代推荐等级时，每差 1 级 -15%，最多 -45%。

### 召唤槽

- 后现代（时代 3）起可以在升级面板解锁，星际（时代 4）起保底自动补到 1 级。
- 每过一段时间造一个友方僵尸。同时能站多少看「预算」：小兵占 1、巨尸占 2；1-5 级预算 2 / 2 / 3 / 3 / 4。
- 五级五兵种，等级越高出怪权重越偏向后解锁的兵种：
  - 盾尸：80 血 / 14 伤，0.8 秒一拳，肉盾。
  - 疾尸：50 血 / 9 伤，0.45 秒一拳，跑得快。
  - 爆尸：60 血，贴身自爆，半径 1.8 内 55 伤害；被打死也会炸。
  - 酸吐尸：55 血 / 每发 8 伤 / 1.1 秒，停在 4.5 距离外吐酸。
  - 巨尸：220 血 / 35 伤 / 1.0 秒一拳，占 2 个预算，同时最多 1 只。
- 升级时免费送一只新解锁的兵种，之后第一只也优先出它。
- 近战友军每 0.7 秒攻击一次，贴身的敌人也会持续伤害它；所有友军有 12 秒寿命，死亡不扣玩家兵。
- 生物人军团和病毒炸弹转化的友军不占召唤槽预算。
- 时代只换外观：后现代克隆舱、星际虫巢、终幕虚空裂隙。

## 一次性技能

每 2 波自动获得一个当前时代的技能，完全随机，不弹选择、不慢放。技能存进屏幕左侧的技能栏，给 N 次使用机会。点左侧图标或按数字键 1-4 使用。

- 技能栏最多存 4 种技能。
- 同一种技能最多叠 9 次。
- 两次使用之间有 0.3 秒冷却，防止连点。
- 只在当前时代的 5 个技能里等概率抽取；不按强度加权，`docs/技能强度权重.md` 只作平衡参考。
- 兵不够献祭时使用不会扣次数。

### 次数分档

| 次数 | 技能 |
| --- | --- |
| 1 次 | 重启、献祭、终焉审判、宇宙坍缩、轨道轰炸（一局只能用一次） |
| 3 次 | 圣水、伞兵增援、空投补给、生物人军团、虫洞 |
| 2 次 | 其余技能，包括舰载无人机群 |

### 技能栏满了怎么办

再抽到新技能时，自动替换最早获得的那个技能（FIFO），并按被替换技能的剩余次数和强度折算成兵：

| 技能档位 | 每剩 1 次折算 |
| --- | --- |
| 1 次技能 | +12 兵 |
| 2 次技能 | +8 兵 |
| 3 次技能 | +5 兵 |

### 地图结束升级

每张地图结束（每 3 波）打开升级面板：游戏完全暂停 30 秒，列出所有还能升级的槽位和基础卡，选 3 次。选满 3 次立即关闭并继续游戏；30 秒没选完，剩余次数累计到下一次，下次可以一起选。手机排 2 列、电脑排 3 列，每个升级项带 emoji。

自动获得技能时，左侧技能栏里对应的格子会金色高亮一次。

### 换时代

进入新一个时代时，旧时代技能不能继续用，按剩余次数和上表折算成兵，然后清空。例如箭雨剩 2 次，折算 +16 兵。

### 怎么选目标

| 类型 | 目标位置 |
| --- | --- |
| 范围（aoe） | 场上最密的一点。以每只僵尸为中心，数半径 3 内有多少同伴，取同伴最多的那只的位置；场上没有僵尸时落在 (0, -6) |
| 横排（line） | 以最密点的 `z` 为中线，上下各 `半宽` 内、横向贯穿全屏的所有僵尸 |
| 全场（slow / freeze / buff / heal / clear） | 不需要选点，直接作用于全场或全队 |

减速不叠加：后来的减速会直接覆盖前一个的倍率和结束时间，即使技能不同也一样。基因爆发同理，后来的射速倍率覆盖前一个。熵增的减速被覆盖后，它的持续掉血仍然继续到自己的 5 秒结束。

### 终幕

| 技能 | 类型 | 具体效果 |
| --- | --- | --- |
| 终焉审判 | 处决 | 全场生效，**不看位置也不看半径**：生命 **≤50% 最大生命**的僵尸立即处决并照常计分；没到阈值的各受 **20% 最大生命**伤害。Boss 不处决，改吃 **30% 最大生命** |
| 宇宙坍缩 | 聚怪 + 比例压制 | 半径 14 内的僵尸拉向最密点，走完距离的 85%；然后按**被吸之前**离中心的距离结算：6 以内扣 **35% 最大生命**，6~14 扣 **15%**，Boss 两档都 ×0.5。拉完大家都会贴在中心，所以档位必须按吸引前的位置算 |
| 献祭 | 百分比削血 | 士兵必须 **多于 20** 才能发动。消耗 20 兵，全场僵尸的**生命上限与当前生命一起 ×0.5**（Boss ×0.75）；不致死（至少留 1 血）、不直接计分。兵不够或场上没有僵尸时不发动、不扣次数 |
| 重启 | 撤回 | 全场僵尸**不计分**消失（没有击杀结算，自爆僵尸也不会连锁）；士兵回补到本局**峰值的 80%**；随后 3 秒不刷怪 |
| 熵增 | 递增减速 + 百分比掉血 | 持续 8 秒：全场移动从 ×0.5 起，每秒再乘 0.88（最低 ×0.18），越拖越慢；期间每秒掉 **3% 最大生命**（8 秒共 24%），不致死（至少留 1 血），也不计分 |

终幕这一档刻意用三种**不同的计量单位**，因为它们面对的是一条无限上涨的血量曲线（普通僵尸 `20 + (波-1)×8`，第 46 波 380 血、第 66 波 540 血，而子弹单发只有 6.2~12.4）：

- 终焉审判按**血量百分比阈值**结算 —— 越到后期越容易满足条件，不会贬值
- 献祭按**全场总血量的比例**结算 —— 和僵尸有多少血无关
- 重启按**士兵峰值的比例**结算 —— 和敌人强度无关
- 宇宙坍缩按**落点距离分档的百分比**结算 —— 靠聚怪，不靠伤害数字
- 熵增按**最大生命百分比**持续掉血 + 递增减速 —— 拖时间，不靠每秒固定 DPS

固定数值（旧的 200 / 300 伤害、每秒 8 点、80 点范围伤害）在第 24 / 37 波之后连一只普通僵尸都打不死，所以几张牌会一起退化成"清屏"，这是这轮改版要解决的问题。

## 效果类型

技能共用几套通用逻辑，正式特效由乙按 `docs/美术需求-槽位与技能.md` 替换：

- `aoe`：落点圆形范围伤害
- `line`：贯穿全屏的横排伤害（目前没有技能使用）
- `airStrike`：3 个最密点的多点轰炸
- `barrage`：大范围持续洗地
- `napalmWall`：矩形火墙，持续伤害并减速
- `rollingLog`：从左侧滚出的纵向滚木，沿途单体伤害
- `knightCharge`：从下方冲出的骑士，向上贯穿并单体伤害
- `tank`：底部槽位后方的坦克，打一轮炮后撤退
- `apc`：向上冲锋的装甲车，撞击 + 机枪
- `carrierDrones`：舰载无人机群，持续一波
- `orbital`：横向光柱，清掉离士兵最近的 2/3，一局一次
- `droneSwarm`：一波内陆续放出 N 架自杀式无人机，随机锁定目标后撞上去小范围爆炸
- `weaponDrop`：空投重武器，限时提升子弹伤害和射速
- `virusBomb`：病毒炸弹，把范围内敌人转成友方
- `friendlyLegion`：瞬间生成一批友方僵尸
- `campfire`：地面持续火区，范围内每秒伤害
- `slow`：全场减速，可附带每秒持续伤害
- `freeze`：全场原地停顿
- `buff`：全队射速倍率
- `heal`：回兵
- `pull`：按半径把僵尸拉向落点
- `warp`：把最靠前的僵尸送回出生点
- `execute`：按血量百分比全场处决，不看位置（终焉审判）
- `sacrifice`：扣兵把全场生命上限与当前生命按比例砍掉（献祭）
- `reboot`：不计分清场，并按本局峰值回补士兵（重启）
- `clear`：清空场上僵尸并照常计分（目前没有技能使用）
- `plague`：记忆植入的传染炮弹，落点感染并持续扩散

## 状态字段

`game.js` 里和技能相关的运行状态：

| 字段 | 含义 |
| --- | --- |
| `state.slowUntil` / `slowMul` | 减速结束时间和倍率；`state.time` 超过 `slowUntil` 后失效 |
| `state.freezeUntil` | 冻结结束时间；期间僵尸不移动、不啃墙 |
| `state.entropyUntil` / `entropyDps` | 熵增的持续伤害截止时间和每秒伤害 |
| `state.campfireZones` | 篝火火区列表，每项带位置、半径、剩余时间、圆心每秒伤害和边缘衰减比例 |
| `state.napalmWalls` | 燃烧弹火墙列表，每项带中心、宽、纵深、剩余时间和每秒伤害 |
| `state.skillBag` | 技能栏，每项是 `{ id, charges }`；使用、替换、换时代都会改这个数组 |
| `state.skillUseCd` | 技能使用冷却，0.3 秒 |
| `state.usedSkills` | 一局只能用一次的技能，目前只有轨道轰炸 |
| `state.peakSoldiers` | 本局士兵数历史最高值，每帧在 `update()` 里刷新；重启按它算回补目标 |
| `state.tankSupports` | 坦克支援数组，每项 `{ id, x, z, shotsLeft, timer, retreating, retreatDelay }`；空数组表示不在场 |
| `state.apcCharges` | 装甲车列表 |
| `state.carrierDrones` | 舰载无人机列表，每架记录圆心、相位、剩余寿命 |
| `state.friendlyZombies` | 友方僵尸，召唤槽、生物人军团和病毒炸弹共用 |
| `state.virusBombs` | 正在下落的病毒炸弹 |
| `state.weaponBoostUntil` / `weaponBoostDamage` / `weaponBoostRate` | 空投重武器的结束时间、伤害倍率和射速倍率 |
| `state.buffUntil` / `buffMul` | 攻速加成结束时间和倍率 |
