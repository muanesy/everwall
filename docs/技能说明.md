# 技能说明

卡面上的描述来自 `game.js` 的 `SKILL_DESCS`，改描述只改那里。这份文档写的是实际代码效果，卡面放不下的细节都记在这里。

## 测试模式

主界面有一个「测试模式」开关，打开后开始按钮变成「开始测试」。进游戏后屏幕左侧出现测试面板：

- 6 个时代按钮，点了立刻换时代和地图，不受波次影响
- 5 个槽位（攻城、近防、支援、指挥、工事），可以 +/- 调 1-5 级，面板上直接显示当前数值
- 30 个一次性技能按钮，点一下立刻释放，不受当前时代限制
- 「刷 20 只僵尸」和「清空僵尸」，方便反复测技能

测试模式里士兵不会掉血，僵尸也啃不动路障；士兵子弹命中僵尸不掉血；炸药桶不生成、不触发；波次不再触发抽卡。技能、槽位和路障反击的伤害照常生效。

`src/game.js` 里不再有 `UNLOCK_ALL_SLOTS_FOR_TEST` 这个常量，正常进游戏时槽位全部锁定，靠抽卡解锁和升级。

## 五个槽位

槽位有 1-5 级。时代决定科技家族，等级决定伤害、半径、间隔、回兵数和路障血量。完整数值见 `docs/槽位升级数值.md`。

下表是 1 级、中世纪的基准值，实际值还会乘时代倍率和欠级折扣。

| 槽位 | 位置 | 1 级基准 | 节奏 |
| --- | --- | --- | --- |
| 攻城 | (4.5, 15) | 打最密的一群，半径 2.6，30 伤害 | 每 6 秒 |
| 近防 | (5.5, 4.5) | 打身边 3 单位内的僵尸，8 伤害 | 每 0.5 秒 |
| 支援 | (-4.5, 15) | 回复 1 个兵 | 每 10 秒 |
| 指挥 | (0, 15) | 全队射速 +5% | 常驻 |
| 工事 | z=0，路障 | 240 血、无反击、宽 4.2 | 碎了 10 秒重建 |

最终数值 = 基础值 × 时代倍率 × 等级倍率 × 欠级折扣。低于时代推荐等级时，每差 1 级 -15%，最多 -45%。

## 一次性技能

抽到立刻释放，没有冷却。卡池里只出现当前时代的 5 个技能。兵不够献祭、路障已经满级时，「献祭」和「记忆植入」不会出现在卡池里。

### 怎么选目标

| 类型 | 目标位置 |
| --- | --- |
| 范围（aoe） | 场上最密的一点。以每只僵尸为中心，数半径 3 内有多少同伴，取同伴最多的那只的位置；场上没有僵尸时落在 (0, -6) |
| 横排（line） | 以最密点的 `z` 为中线，上下各 `半宽` 内、横向贯穿全屏的所有僵尸 |
| 全场（slow / freeze / buff / heal / clear） | 不需要选点，直接作用于全场或全队 |

减速不叠加：后来的减速会直接覆盖前一个的倍率和结束时间，即使技能不同也一样。基因爆发同理，后来的射速倍率覆盖前一个。熵增的减速被覆盖后，它的持续掉血仍然继续到自己的 5 秒结束。

## 效果类型

技能共用几套通用逻辑，正式特效由乙按 `docs/美术需求-槽位与技能.md` 替换：

- `aoe`：落点圆形范围伤害
- `line`：贯穿全屏的横排伤害
- `rollingLog`：从左侧滚出的纵向滚木，沿途单体伤害
- `knightCharge`：从下方冲出的骑士，向上贯穿并单体伤害
- `campfire`：地面持续火区，范围内每秒伤害
- `slow`：全场减速，可附带每秒持续伤害
- `freeze`：全场原地停顿
- `buff`：全队射速倍率
- `heal`：回兵
- `pull`：按半径把僵尸拉向落点
- `warp`：把最靠前的僵尸送回出生点
- `sacrifice`：扣兵换全屏伤害
- `clear`：清空场上僵尸
- `upgradeSlot`：路障解锁或升级

## 状态字段

`game.js` 里和技能相关的运行状态：

| 字段 | 含义 |
| --- | --- |
| `state.slowUntil` / `slowMul` | 减速结束时间和倍率；`state.time` 超过 `slowUntil` 后失效 |
| `state.freezeUntil` | 冻结结束时间；期间僵尸不移动、不啃墙 |
| `state.entropyUntil` / `entropyDps` | 熵增的持续伤害截止时间和每秒伤害 |
| `state.campfireZones` | 篝火火区列表，每项带位置、半径、剩余时间和每秒伤害 |
| `state.buffUntil` / `buffMul` | 攻速加成结束时间和倍率 |
