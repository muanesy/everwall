# 地图机制

六张地图的外观配置在 `src/visuals.js` 顶部的 `MAPS` 里，包括贴图、地面颜色、雾、灯光和背景物。

这份文档记录每张图想做的玩法差异，以及现在做到哪一步。

## 环境事件（已接）

每张地图固定挂一个环境事件；进入地图时随机决定它落在第 2、3 波，**第一波永远不排环境事件**，让玩家先熟悉屏障和尸潮。到那波开头先给 3 秒警告，再持续 2~6 秒；一张地图只触发一次，暂停和升级面板期间计时冻结。测试模式不会自动触发，但测试面板可以点 6 个按钮直接触发任意一类事件，天气还能先选 6 种天气类型。

3 秒警告期间 HUD 顶部会显示「环境事件 · 3s 后生效」的倒计时条。注意有些地图本来就有环境雨（城市、高架等），那是地图氛围，不是事件效果；事件真正的雾拉近、减速和伤害都要等倒计时结束才生效。

| 事件 | 地图 | 对僵尸 | 对玩家 |
| --- | --- | --- | --- |
| 地震 | 城堡、村庄、修道院、战壕、地下停车场、时间废墟 | 停顿 **2 秒**，掉 **15%** 最大生命；Boss 停顿 1 秒、掉 7.5% | 移速 ×0.8、子弹散布 ×1.5，持续 3 秒 |
| 陨石 | 沙漠、月球、外星荒漠、黑洞边缘 | 3 个落点，半径 2.6；终幕前每个 70 伤害，**终幕改 25% 最大生命**（Boss 12.5%） | 其中 1 个落在玩家附近，站圈里挨 10 兵 |
| 恶劣天气 | 感染丛林、城市、军事基地、海滩、军港、港口、高架、雪原 | 移速 ×0.85（不下伤害） | 射速 ×0.9，雾拉近、视野变差；雾的浓度和颜色都走渐变（约 0.8 秒淡入，结束后渐出），不再硬切 |
| 毒雾 | 沼泽、废弃医院、隔离区、生化工厂 | 三个毒圈，半径 **5.5**；每秒掉 2% 最大生命，终幕 3% | 站在毒区里每秒掉 1 兵；新增全屏绿色毒雾层，比天气浓雾淡一档，能看清脚下和僵尸轮廓 |
| 熔岩喷发 | 熔岩、虚空神殿 | 三个熔岩区，半径 **5.2**；每秒掉 4% 最大生命，终幕 5% | 站在裂缝里每秒掉 2 兵 |
| 电磁风暴 | 空间站、轨道平台 | 停顿 1.5 秒；Boss 0.5 秒（不下伤害） | 射速 ×0.75，持续 2 秒 |

> 终幕（era 5）只给**会造成伤害**的事件加百分比：地震、陨石、毒雾、熔岩。天气和电磁保持控制定位，不叠伤害，否则玩家会同时吃减速和掉血，失去走位空间。地震的 2 秒停顿和 15% 掉血是全时代生效，不只终幕。

天气按地图换皮：感染丛林/城市/军港/港口是暴雨，沼泽是浓雾，海滩是风暴，军事基地是沙尘，高架是强风，雪原是暴雪。

地震的玩家负面确实生效：持续 3 秒，玩家移速 ×0.8、子弹散布 ×1.5；僵尸停顿 2 秒并掉 15% 最大生命。屏幕震动在 2026-11-03 加强过：地震期间震动强度 0.34~0.60，相机位移再 ×2.2，普通受击仍按原幅度。

代码落点：`game.js` 的 `MAP_ENV` / `ENV_EVENTS` / `updateEnvEvent()`，画面事件是 `envWarning` / `envZoneStart` / `envQuake` / `envEmp` / `envWeatherStart` / `envWeatherEnd`。

## 规则和机制的区别

**规则**：只改数字。僵尸快慢、刷新密度、出生距离、移速系数。半小时能做完，不容易引入 bug。

**机制**：加新东西。洪水、灼烧、打滑。要新代码、新特效、新 UI，还要重新调平衡。

三天项目里，规则可以做，机制要谨慎。没做完的机制不要留半成品在代码里，先在表里标成“未做”。

## 以后接规则时放哪里

规则属于玩法，写进 `src/game.js`，不要写进 `visuals.js`。

大致长这样：

```
const MAP_RULES = {
  city: {},
  moon: { zombieSpeed: 0.8 },
  desert: { spawnDistance: 0.7 },
};

const mapId = new URLSearchParams(location.search).get('map') || 'city';
const rules = MAP_RULES[mapId] || {};
```

然后在刷僵尸、移动这些地方乘上系数，没配置的地图默认是 1。

画面层不用知道规则，照常只读 `state`。

## 怎么预览

开始页有地形按钮，点一下会带参数刷新。

也可以直接改地址：

```
?map=city ?map=jungle ?map=desert
?map=moon ?map=snow ?map=lava
```
