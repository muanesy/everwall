## 出场权重

按波次解锁，没解锁的权重是 0。解锁后按这个公式算：

```
权重 = 基础权重 + (波次 - 解锁波次) × 每波变化
```

再夹到上下限。第一波只有普通、快鬼、女僵尸，比例大约 60% / 26% / 14%。第二波加入大块头，第三波加入精英。

到第 10 波，比例大约是普通 36%、大块头 22%、快鬼 19%、精英 8%、女僵尸 10%。精英压在 10% 以内，避免变成子弹海绵。

## 强度和奖励随时间的变化

**僵尸强度**

| 项目 | 公式 |
| --- | --- |
| 血量 | `20 + 8 × (波次 - 1)` |
| 速度 | `3.2 + 0.25 × (波次 - 1)`，上限 7.5 |
| 刷新间隔 | `max(0.16, 0.35 - 0.02 × (波次 - 1))` |
| 类型配比 | 见上面的权重公式 |

**奖励**

| 项目 | 公式 |
| --- | --- |
| 普通屏障 | `min(5, 1 + floor((波次 - 1) / 3))` |
| 负数屏障初始值 | 在 `-10` 到 `-(30 + 3 × (波次 - 1))` 之间随机 |
| 负数屏障打满上限 | 在 `10` 到 `30 + 4 × (波次 - 1)` 之间随机 |
| 复活兵力 | `20 + 3 × 波次` |

击杀掉落暂时没做。分数按类型给：普通 1、快鬼 1、女僵尸 2、大块头 3、精英 5。

这样后期屏障和负数屏障的收益都在涨，玩家愿意冒险去左边，经济才转得起来。

## 外观怎么做（乙负责）

- 体型：大块头 1.25，快鬼 0.85，精英 1.1，其余 1.0
- 色调：见总表。精英的灰白在暗图上要稍微提亮，必要时加一点自发光
- 走路动画速度：大块头 0.85 倍，快鬼 1.3 倍，其他 1.0。这一点比颜色更能传达“笨重”和“快”
- 色块回退版 `makeZombieMesh` 的颜色数组要补到 5 个，否则模型加载失败时又全一样

## 数值怎么调（甲负责）

全部在 `game.js` 的 `CONFIG.zombie.types` 里：

```
{ id, name, hp, speed, touchLoss, score, baseWeight, growth, minWeight, maxWeight, minWave }
```

- `hp` / `speed` 是乘在波次基础值上的倍率
- `touchLoss` 是这只僵尸贴上士兵时扣几个兵
- `score` 是击杀得分，只影响右上角分数，不加兵
- `baseWeight` 是刚解锁时的权重，`growth` 是每波增减，`minWeight` / `maxWeight` 是上下限
- `minWave` 是解锁波次

调之前先看 `state.spawnCounts`，它记录每种僵尸实际刷了多少只，用来确认权重有没有生效。

## Boss（已做）

- 模型：`assets/models/b-boss-creep.glb`，Quaternius CC0，17 条动画，已压到 1.87MB
- 动画：`Roar_Action` 登场、`JumpIn_Action` 跳入、`Bite_Action` / `Punch_Action` 攻击、`Walk1_Action` / `Walk2_Action` 行走、`Damage_Action` 受击、`Death_Action` 死亡
- 类型：`type 10`，不进入权重池，每换一张地图（每 3 波）单独刷一只
- 当前数值：血量 ×35、速度 ×0.5、碰兵 6、分数 40
- 行为：走到阵型前沿（`CONFIG.world.touchZ`）**停下连续出拳**，不穿过阵型、也不会在贴线那一刻消失。
  - 每一拳扣 **20 兵**（`CONFIG.boss.attackLoss`），走 `armyHurt`（cause = `boss`）
  - **上一拳的动作演完才打下一拳**：画面层播完 `Bite_Action` 派 `bossAttackDone`，玩法层收到才放行；拿不到回调时按 `attackFallback` 2.0 秒兜底
  - 出拳片段原长 4.8 秒（整包共用一条时间轴），画面层按 `attackAnim` 1.6 秒做时间缩放，所以实际节奏是「1.6 秒咬人 + 0.3 秒收招」
  - 收招期间保持咬完的姿势，不再切回走路：以前每拳结尾都会闪回走路 0.15 秒再切回攻击，看起来像抽搐
  - 被虫洞/击退推回半场就停拳，重新走上来会再开始
- 血条：Boss 就是 `type 10` 的僵尸，靠 `maxHp` 显示头顶血条
- `state.spawnCounts` 按僵尸类型 id 扩容，Boss 单独计数

接入时先看仓库根目录的 `交接-Boss接入(1).md`。

## 风险

- 精英 3.5 倍血是起步值，玩家火力不够时会堆积。先按 6% 权重试，不行降到 4%
- 大块头碰兵扣 2，在阵型判定变宽后可能偏狠，优先观察这一项
- 女模型面数是男模型的两倍多，type 3 和 4 都用女模型。低端机掉帧的话，把 type 4 换成男模型换个色
