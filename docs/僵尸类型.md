# 僵尸类型

`z.type` 固定为 0 到 4，这个编号是 `game.js` 和 `visuals.js` 之间的约定，改编号必须两边一起改。

数值归 `game.js`，外观归 `visuals.js`。

## 出场权重

按波次解锁，没解锁的权重是 0。解锁后按这个公式算：

```
权重 = 基础权重 + (波次 - 解锁波次) × 每波变化
```

再夹到上下限。第一波只有普通、快鬼、女僵尸，比例大约 60% / 26% / 14%。第二波加入大块头，第三波加入精英。

到第 10 波，比例大约是普通 36%、大块头 22%、快鬼 19%、精英 8%、女僵尸 10%。精英压在 10% 以内，避免变成子弹海绵。

## 强度和奖励随时间的变化

**僵尸强度**

| 项目 | 公式 |
| --- | --- |
| 血量 | `20 + 8 × (波次 - 1)` |
| 速度 | `3.2 + 0.25 × (波次 - 1)`，上限 7.5 |
| 刷新间隔 | `max(0.16, 0.35 - 0.02 × (波次 - 1))` |
| 类型配比 | 见上面的权重公式 |

**奖励**

| 项目 | 公式 |
| --- | --- |
| 普通屏障 | `min(5, 1 + floor((波次 - 1) / 3))` |
| 负数屏障初始值 | 在 `-10` 到 `-(30 + 3 × (波次 - 1))` 之间随机 |
| 负数屏障打满上限 | 在 `10` 到 `30 + 4 × (波次 - 1)` 之间随机 |
| 复活兵力 | `20 + 3 × 波次` |

击杀掉落暂时没做。分数按类型给：普通 1、快鬼 1、女僵尸 2、大块头 3、精英 5。

这样后期屏障和负数屏障的收益都在涨，玩家愿意冒险去左边，经济才转得起来。

## 外观怎么做（乙负责）

- 体型：大块头 1.25，快鬼 0.85，精英 1.1，其余 1.0
- 色调：见总表。精英的灰白在暗图上要稍微提亮，必要时加一点自发光
- 走路动画速度：大块头 0.85 倍，快鬼 1.3 倍，其他 1.0。这一点比颜色更能传达“笨重”和“快”
- 色块回退版 `makeZombieMesh` 的颜色数组要补到 5 个，否则模型加载失败时又全一样

## 数值怎么调（甲负责）

全部在 `game.js` 的 `CONFIG.zombie.types` 里：

```
{ id, name, hp, speed, touchLoss, weight, minWave }
```

- `hp` / `speed` 是乘在波次基础值上的倍率
- `touchLoss` 是这只僵尸贴上士兵时扣几个兵
- `weight` 是出场权重，`minWave` 是解锁波次

调之前先看 `state.spawnCounts`，它记录每种僵尸实际刷了多少只，用来确认权重有没有生效。

## 风险

- 精英 3.5 倍血是起步值，玩家火力不够时会堆积。先按 6% 权重试，不行降到 4%
- 大块头碰兵扣 2，在阵型判定变宽后可能偏狠，优先观察这一项
- 女模型面数是男模型的两倍多，type 3 和 4 都用女模型。低端机掉帧的话，把 type 4 换成男模型换个色
