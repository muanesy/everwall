# 槽位与一次性技能：美术需求清单

给乙看的。玩法数值和触发时机在 `game.js`，这里只列需要做的模型、动画和特效。

## 通用规格

- 模型统一 GLB，单个文件不超过 2MB
- 面数：建筑和载具不超过 5k，角色不超过 16k
- 贴图不超过 1024，优先复用同一套材质
- 特效优先程序化粒子、Sprite、几何体，不要视频和序列帧
- 音效走 `audio.js` 合成，不加音频文件
- 每个槽位先做一套基础模型，再用换色、换附件做时代变体，不要每个时代从零建模
- 命名：`b-slot-{槽位}-{时代}.glb`、`b-skill-{技能}.glb`、`b-vfx-{效果}.png`

## 五个槽位

每个槽位需要：一个基础模型、1 到 2 个动画、1 套特效、3 段破损状态（工事专用）。位置和血量由甲控制，乙只负责长相和特效。

## 一次性技能

共 30 个。按特效类型分组做，同一套系统换颜色和投射物。

### 第一组：范围打击（最优先，一套系统覆盖八个技能）

需要：落点预警圈、爆炸火球、冲击波、屏幕震动、尘埃。

- 箭雨：箭矢 Sprite 从上方落下 + 地面尘土
- 空袭：轰炸机剪影 + 一排爆炸
- 炮火覆盖：横线连续爆炸
- 精确打击：激光指示线 + 单点爆炸
- 轨道轰炸：垂直光柱 + 地面熔融
- 舰队齐射：多道光束同时落下
- 终焉审判：全屏白光 + 黑红冲击
- 宇宙坍缩：向中心收缩的粒子 + 内爆

### 第二组：移动单位

需要：模型 + 移动动画 + 路径碾压特效。

- 滚木：纵向长条圆柱，带树皮纹理，从左往右横滚，滚动时能看到节疤旋转
- 骑士冲锋：3 个骑马骑士，从屏幕下方右侧并排向上冲，长枪指向前方
- 坦克支援：二战坦克，履带和炮塔
- 装甲车冲锋：现代装甲车，轮子转动

### 第三组：控制与增益

大多是全屏或地面特效，不需要新模型。

- 电磁脉冲：蓝色冲击波 + 屏幕轻微扭曲
- 时间减速：蓝色滤镜 + 钟表粒子
- 时间膨胀：慢放滤镜 + 拖影
- 熵增：灰黑色衰败粒子 + 僵尸掉血闪烁
- 基因爆发：绿色光环 + 速度线
- 篝火：半径 3.5 的范围圈 + 石圈 + 交叉木柴 + 三层火苗（橙/黄/白）+ 上升火星 + 暖光，跟着火区一起持续 5 秒
- 燃烧弹：火区 + 黑烟
- 圣水：金色/绿色净化环

### 第四组：召唤与特殊

成本最高，放最后。

- 生物人军团：己方僵尸模型 + 召唤阵
- 病毒炸弹：绿色毒雾 + 感染扩散
- 黑洞：黑色球体 + 吸积盘 + 引力扭曲
- 虫洞：环形传送门 + 吸入/吐出
- 伞兵增援：伞兵模型 + 降落伞
- 空投补给：补给箱 + 降落伞
- 献祭：红色法阵 + 士兵消散
- 重启：时间倒流滤镜 + 场景闪回
- 记忆植入：卡牌 UI 特效，不需要 3D

## 优先级

1. **P0**：范围打击通用系统（预警圈、爆炸、光柱、火区），一次覆盖八个技能
2. **P1**：五个槽位的基础模型（先做现代一套）+ 工事三段破损 + 血条和倒计时
3. **P1**：移动单位里的滚木、坦克、装甲车
4. **P2**：时代变体（换色、换附件）
5. **P2**：召唤、黑洞、虫洞、重启这些特殊技能

## 交付方式

- 每个模型给 GLB + 一张预览截图
- 动画命名写清楚，比如 `Idle`、`Fire`、`Break`
- 特效说明用哪个粒子池、什么颜色、持续多久
- 文件放进 `assets/models/` 或 `assets/vfx/`，在文档里登记
- 不要改 `game.js` 的数值，位置、血量、冷却、伤害都归甲

## 和玩法层的接口

- 槽位：`game.js` 维护位置、血量、冷却；`visuals.js` 只读 state 画模型和血条
- 技能：`game.js` 发 `skillCast` 事件，带技能 id、落点 x/z；`visuals.js` 播放特效；伤害由 `game.js` 结算
- 音效：`audio.js` 提供合成接口，新技能加一个音色参数即可
