# 时代地图

每个时代可以有多张地图。进入时代时从该时代的图池里随机抽 3 张，每张打 3 波，三张打完才进下一个时代。

开始页可以选择起始时代（`?era=`）。选时代会顺手把地形切到该时代的第一张图；起始波次按 `时代 × 9 + 1` 走，僵尸强度自动跟时代对齐。

开局还按时代送一段基础配置：中世纪什么都不给；二战/现代给 1 级穿透器 + 1 级火力增援；后现代起再给全部槽位，等级跟时代走（后现代 1、星际 2、终幕 3）。

## 乙做一张新图要交什么

1. `map id` 和中文名，以及所属时代
2. 2 到 3 张地面贴图（diff / normal / rough），单张不超过 1MB，建议 512 或 1024
3. 6 到 10 个背景物，优先程序化几何体，少用大模型
4. 雾色、灯光、地面乘色
5. 一种空气粒子（雨、尘、雪、火星、雾等）
6. 一条环境音染色，复用 `audio.js` 的参数，不加音频文件
7. 在三个地方登记：
   - `src/visuals.js` 的 `MAPS`
   - `src/ui.js` 的 `MAP_LIST`
   - `src/visuals-era.js` 对应时代的 `maps` 数组

## 代码怎么选图

- `eraMaps(eraIndex)` 返回该时代全部地图
- `pickEraMap(eraIndex, used)` 随机挑一张，尽量避开本局用过的
- `pickEraMapSet(eraIndex, preferred)` 在 `game.js` 里，随机抽 3 张；开始页选中的地图排第一
- 换时代时的写法：

```
state.eraMaps = pickEraMapSet(eraIndex);
state.mapIndex = 0;
const map = state.eraMaps[0];
switchEra(eraIndex, map);
```

- 某个时代不足 3 张时循环补足，不会报错
- `eraMaps` / `pickEraMap` 都从 `visuals.js` 导出，甲直接 import

## 每个时代 3 张地图

- 时代索引 = `min(5, floor((波次 - 1) / 9))`
- 当前时代内的地图序号 = `floor(((波次 - 1) % 9) / 3)`
- 第 4、7、10……波换地图；同时代内换图只调 `switchMapLook(map, { fade: true })`，不重播时代配色、不折算技能、不改 `state.era`
- 每换一张地图补一只 Boss；场上已经有一只时 `spawnEraBoss` 会自己跳过
- 终幕（时代 5）没有下一个时代，三张打完会重新抽一组 3 张继续轮换，时代保持不变

对应代码：`src/game.js` 的 `syncEraWithWave(wave)`，时代和地图序号都由波次算出来。

## 注意

- 每张新图都要过 `keepOffArena` 安全区检查，别把背景物放进战斗通道
- 新图如果要有专属僵尸，同步改 `src/visuals.js` 的 `MAP_TYPE_SRC`，否则还是默认僵尸
- 手机性能：背景物和粒子按现有图的量来，不要翻倍
- 开局地图选择器现在列了全部九张，和时代绑定后会有冲突。先把它当成“起始地图”，进入时代后由时代系统接管；或者之后改成只列第一个时代的地图
