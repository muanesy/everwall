# 接口约定

两个人同时写代码，靠这份约定保证拼得起来。改动接口前先在群里说一声，两边一起改。

## 分工边界

- `src/game.js` 维护数据，负责改
- `src/visuals.js`、`src/ui.js` 只读数据，负责画
- 画面层不要直接改 `state` 里的任何字段

## 游戏状态 state

由 `game.js` 创建和维护，作为参数传给画面层。

```
state = {
  status: 'menu' | 'playing' | 'over',
  time: 本局已进行秒数,
  wave: 当前波次，从 1 开始,
  score: 分数,
  soldiers: 士兵数量。同时是生命值，归零就结束,

  player: {
    x: 左右位置（-8 到 8）,
    z: 纵深位置（固定 9）
  },

  weapon: {
    lines: 枪位数量，默认 1，最高 8,
    spread: 是否解锁了扩散器
  },

  formation: {
    frontCount: 前排人数，由士兵总数算出来
  },

  bullets: [
    { id, x, z, vx, vz, damage }
  ],

  barriers: [
    { id, kind, x, z, value, maxValue, hits, required, length, halfWidth, speed }
  ],

  zombies: [
    { id, x, z, hp, speed, touchLoss, type, aggro }
  ]
}
```

## 坐标和分区

这是俯视角。`x` 是左右，`z` 是纵深（屏幕上下），`y` 是高度。

| 名字 | 值 | 含义 |
| --- | --- | --- |
| 玩家位置 | `z = 9` | 屏幕下方 |
| 出生位置 | `z = -26` | 屏幕上方之外 |
| 进入屏幕 | `z = -21.5` | 越过这条线，+1 屏障才能被打中 |
| 防线 | `z = 8.4` | 僵尸越过这里，士兵减员 |
| 左区 | `x` 在 -7.6 到 -0.6 | +1 屏障出现的地方 |
| 右区 | `x` 在 0.6 到 7.6 | 僵尸出现的地方 |

## 事件

`game.js` 用 `events.dispatchEvent(new CustomEvent(...))` 发出，`visuals.js` 监听。

| 事件名 | 触发时机 | detail |
| --- | --- | --- |
| `shoot` | 玩家开火 | `{ origins, x, z }`，origins 是每个枪位的 `{ x, z }` |
| `barrierHit` | 子弹打中负数屏障或特殊屏障一次 | `{ x, z, value }` 或 `{ x, z, kind, hits, required }` |
| `weaponUpgrade` | 武器强化屏障攒够命中，枪位 +1 | `{ lines }` |
| `spreaderUnlock` | 扩散器攒够命中 | `{}` |
| `barrierApply` | 屏障数值生效（达到上限或碰到士兵） | `{ x, z, value }` |
| `zombieDie` | 僵尸死亡 | `{ x, z, type }` |
| `armyHurt` | 僵尸碰到士兵，或碰到负数屏障 | `{ soldiers, amount, cause }`，cause 是 `'touch'` 或 `'barrier'` |
| `waveStart` | 进入新一波 | `{ wave }` |

新增事件时，两边都要改：`game.js` 里 emit，`visuals.js` 里 addEventListener。

## 画面层必须提供的函数

`game.js` 会调用这两个：

```
initVisuals(container, events)
  初始化场景。只调用一次。

syncScene(state, dt)
  每帧调用。dt 是距上一帧的秒数。
  负责把 state 画出来，并更新特效动画。
```

`ui.js` 必须提供：

```
initUI(state, actions)
  actions = { start, restart, revive }
  初始化界面。只调用一次。

updateUI(state)
  每帧调用。根据 state 更新士兵数、分数、显示哪一层界面。
```

## 几条规则

- 屏障在 `z < -21.5` 时不可被击中，哪怕子弹从它身上穿过
- 屏障从左边界一直铺到中间，但同一批在纵向上错开 8 个单位，不会排成一条直线
- 屏障分四类：绿色普通、红色负数、蓝色武器强化、紫色扩散器
- 普通屏障一发碎，加当前 `+N`，`+N` 随波次从 +1 升到 +5
- 负数屏障越到后期越多、越长，最多占 3 个格子。打一发数值 +1，打满上限或碰到士兵时结算
- 武器强化屏障需要攒够命中（`30 + 6 × 波次`），攒够后枪位 +1，最多 8 个
- 扩散器需要攒够命中（`20 + 4 × 波次`），攒够后枪口抖动变大，弹道轻微散开
- 武器强化和扩散器没攒够就消失，不生效，碰到士兵也不生效
- 默认只有 1 个枪位，子弹从前排士兵的位置射出。总射速由士兵数决定，枪位变多时每个枪位变慢，总子弹数不变
- 枪位均匀分布在前排，最多 8 个
- 平常枪口有轻微抖动，扩散器解锁后抖动幅度变大，但依然是小角度，不是扇形
- 僵尸不会越线：走到 `z = 8.4` 就停住，沿防线以 15 的速度滑向士兵，直到贴上
- 僵尸在 `z > 1` 且离士兵 6 以内开始主动拐弯，侧向速度 3.8，其余时间走直线
- 僵尸的接触判定用阵型半宽：`0.9 + min(0.6, 士兵数 × 0.04)`，人越多阵型越宽
- 僵尸到线滑行时会朝移动方向前倾，脚下有尘土，用来掩盖最后一段横移
- 僵尸分 5 种，`type` 0 到 4，数值和外观的约定见 `docs/僵尸类型.md`
- 僵尸贴上士兵时扣 `touchLoss`，不同种类不一样
- 僵尸基础移动速度 3.2，每波还会加快
- 僵尸之间有 0.6 的最小间距，靠太近会互相推开，避免叠成一坨
- 一局开始时士兵是 5 个，复活兵力是 `20 + 3 × 波次`
- 士兵最多同时显示 120 个，站成三角形队列，超出的只体现在 HUD 数字上

## 数值在哪改

全部在 `game.js` 顶部的 `CONFIG` 里。改完保存，Live Server 会自动刷新。

要点：

- `barrier.spawnInterval` 控制屏障压下来的密度
- `barrier.rowGap` 是同一批屏障的横向间隔
- `barrier.staggerRange` 是同一批屏障的纵向错开范围，调大更零散
- `barrier.negativeChanceBase` / `PerWave` / `Max` 控制负数屏障随时间变多的速度
- `barrier.negativeLengthEveryWaves` / `negativeLengthMax` 控制负数屏障变长的速度
- `barrier.weaponChance` / `spreaderChance` 是两种特殊屏障的出现概率，默认各 2%
- `barrier.weaponHitsBase` / `weaponHitsPerWave` 是武器强化的命中要求
- `barrier.spreaderHitsBase` / `spreaderHitsPerWave` 是扩散器的命中要求
- `weapon.maxLines` 是枪位上限，默认 8
- `weapon.jitterBase` / `jitterSpread` 是普通和扩散状态下的枪口抖动
- `formation.spacing` / `rowGap` 是前排横向间距和排间距
- `formation.maxSoldiers` 是士兵的显示上限，默认 120
- `zombie.spawnInterval` 和 `intervalPerWave` 控制僵尸潮的强度
- `zombie.types` 是五种僵尸的倍率、碰兵伤害、权重和解锁波次，想看总表去 `docs/僵尸类型.md`
- `state.spawnCounts` 记录每种僵尸实际刷了多少只，调权重时用
- `zombie.turnSpeed` 是僵尸主动拐弯时的横向速度
- `zombie.lineSlideSpeed` 是僵尸到线后沿防线滑向士兵的速度，必须大于士兵移速，否则会僵持
- `zombie.touchBase`、`touchPerSoldier`、`touchMaxBonus` 控制阵型接触宽度
- `zombie.aggroStartZ` 和 `zombie.aggroRadius` 决定僵尸多近才开始追人
- `zombie.separation` 是僵尸之间的最小间距

调试：浏览器控制台输入 `__state` 可以看实时状态（士兵、僵尸、子弹数量）。

## 换成模型时改哪里

只在 `visuals.js` 里改：

- `playerMesh` 的创建（现在是方块）
- `makeBarrierMesh()`（绿色横条 + 浮动的 +1 标签）
- `makeZombieMesh()`（现在按 type 换颜色）
- 士兵是 `InstancedMesh`，最多同时画 60 个，超出的只体现在 HUD 数字上
- 如果要加载 GLB，用 `GLTFLoader`，导入路径是 `three/addons/loaders/GLTFLoader.js`

`game.js` 不需要知道模型长什么样。
