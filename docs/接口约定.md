# 接口约定

两个人同时写代码，靠这份约定保证拼得起来。改动接口前先在群里说一声，两边一起改。

## 分工边界

- `src/game.js` 维护数据，负责改
- `src/visuals.js`、`src/ui.js` 只读数据，负责画
- 画面层不要直接改 `state` 里的任何字段

## 游戏状态 state

由 `game.js` 创建和维护，作为参数传给画面层。

```
state = {
  status: 'menu' | 'playing' | 'over',
  paused: 是否暂停（只在 playing 时有效）,
  time: 本局已进行秒数,
  wave: 当前波次，从 1 开始,
  score: 分数,
  soldiers: 士兵数量。同时是生命值，归零就结束,
  testMode: 是否测试模式,
  slotLevels: { siege, closeDefense, support, command, summon } 五个槽位等级，0 表示未解锁,
  skillBag: [{ id, charges }] 一次性技能栏，最多 4 种,
  skillBagVersion: UI 重建用的版本号,
  skillUseCd: 技能使用冷却，秒,

  player: {
    x: 左右位置（-8 到 8）,
    z: 纵深位置（固定 9）
  },

  weapon: {
    lines: 枪位数量，默认 1，最高 8,
    pierce: 是否解锁了穿透器,
    pierceLevel: 穿透器等级 0-3（0 未解锁，1-3 对应 8%/12%/16% 继续穿透、最多 3/4/5 次）
  },

  formation: {
    frontCount: 前排人数，由士兵总数算出来
  },

  barricade: {
    hp: 当前血量,
    maxHp: 最大血量,
    active: 是否立着,
    cooldown: 碎掉后的重建倒计时
  },

  slowUntil: 减速结束时间,
  slowMul: 减速倍率,
  freezeUntil: 电磁脉冲冻结结束时间,
  entropyUntil: 熵增持续掉血的结束时间,
  entropyStart: 熵增释放时刻（用来算减速递增）,
  entropyPct: 每秒掉最大生命的比例（0.03）,
  entropyRamp: 减速每秒再乘的系数（0.88）,
  entropyMinMul: 减速下限（0.18）,

  bullets: [
    { id, x, z, vx, vz, damage }
  ],

  barriers: [
    { id, kind, x, z, value, maxValue, hits, required, length, halfWidth, speed }
  ],

  zombies: [
    { id, x, z, hp, maxHp, speed, touchLoss, type, aggro }
  ],

  rollingLogs: [
    { id, x, z, length, radius, speed, damage, spin, hit }
  ],

  knightCharges: [
    { id, x, z, speed, damage, hit }
  ],

  campfireZones: [
    { id, x, z, radius, remaining, dps, falloff }
  ],

  napalmWalls: [
    { id, x, z, width, depth, remaining, dps }
  ],

  siegeShots: [
    { x, z, radius, damage, timeLeft, kind, color }
  ],

  tankSupports: [] | [{ id, x, z, shotsLeft, timer, retreating, retreatDelay }],  // 可以同时存在多辆

  apcCharges: [
    { id, x, z, speed, damage, hit, mgTimer }
  ],

  carrierDrones: [
    { id, x, z, baseX, baseZ, life, mgTimer, phase }
  ],

  friendlyZombies: [
    // 生物人军团 / 病毒转化：只有基础字段
    { id, x, z, hp, maxHp, speed, damage, attackTimer, life, converted },
    // 召唤槽兵种额外带：
    //   unitType 盾尸/疾尸/爆尸/酸吐尸/巨尸 的英文 key
    //   role     同 unitType，玩法层按它选 AI（近战 / 自爆 / 远程）
    //   cost     占多少预算（小兵 1，巨尸 2）
    //   attackInterval、range、explodeRadius、scale
    //   slotUnit=true 表示由召唤槽制造（只有这些占召唤预算）
    { ..., unitType, role, cost, attackInterval, range, explodeRadius, scale, slotUnit }
  ],

  virusBombs: [
    { id, x, z, timeLeft, fallTime, radius, maxConvert }
  ],

  blackHoles: [
    { id, x, z, timeLeft, duration, radius, pullRadius, pullFactor, damagePct, bossPctMul }
  ],

  weaponBoostUntil: 空投重武器结束时间,
  weaponBoostDamage: 子弹伤害倍率,
  weaponBoostRate: 射速倍率,

  usedSkills: [一局只能用一次的技能 id]
}
```

## 坐标和分区

这是俯视角。`x` 是左右，`z` 是纵深（屏幕上下），`y` 是高度。

| 名字 | 值 | 含义 |
| --- | --- | --- |
| 玩家位置 | `z = 9` | 屏幕下方 |
| 出生位置 | `z = -26` | 屏幕上方之外 |
| 进入屏幕 | `z = -21.5` | 越过这条线，+1 屏障才能被打中 |
| 防线 | `z = 8.4` | 僵尸越过这里，士兵减员 |
| 左区 | `x` 在 -7.6 到 -0.6 | +1 屏障出现的地方 |
| 右区 | `x` 在 0.6 到 7.6 | 僵尸出现的地方 |

## 事件

`game.js` 用 `events.dispatchEvent(new CustomEvent(...))` 发出，`visuals.js` 监听。

| 事件名 | 触发时机 | detail |
| --- | --- | --- |
| `shoot` | 玩家开火 | `{ origins, x, z }`，origins 是每个枪位的 `{ x, z }` |
| `barrierHit` | 子弹打中负数屏障或特殊屏障一次 | `{ x, z, value }` 或 `{ x, z, kind, hits, required }` |
| `weaponUpgrade` | 火力增援屏障攒够命中，枪位 +1 | `{ lines }` |
| `pierceUnlock` | 穿透器攒够命中 | `{}` |
| `bulletPierce` | 子弹穿透了一只僵尸 | `{ x, z }` |
| `barrierApply` | 屏障数值生效（达到上限或碰到士兵） | `{ x, z, value }` |
| `zombieDie` | 僵尸死亡 | `{ x, z, type }` |
| `armyHurt` | 普通僵尸碰到士兵、Boss 出拳命中、或碰到负数屏障 | `{ soldiers, amount, cause }`，cause 是 `'touch'`（普通僵尸贴线）、`'boss'`（Boss 一拳）或 `'barrier'` |
| `bossReachLine` | 时代 Boss 第一次贴上防线，开始连续攻击 | `{ id, x, z }` |
| `bossAttack` | Boss 出一拳（**每拳扣 20 兵**） | `{ id, type, x, z, count, animSeconds }`，animSeconds 是这一拳要播多久（画面层据此做时间缩放） |
| `bossAttackDone` | **画面层 → 玩法层**：Boss 出拳动作演完了 | `{ id }`，玩法层收到才允许打下一拳 |
| `waveStart` | 进入新一波 | `{ wave }` |
| `friendlySpawn` | 召唤槽造出一只友军 | `{ x, z, unitType }`（军团和病毒转化不带 unitType） |
| `friendlyDie` | 友军消失 | `{ x, z, unitType }` |
| `blackHoleImpact` | 黑洞吸附结束、结算百分比伤害 | `{ x, z, radius }` |
| `friendlyExplode` | 爆尸自爆 | `{ x, z, radius }` |
| `friendlySpit` | 酸吐尸吐出一发酸液 | `{ fromX, fromZ, x, z }` |
| `barricadeHit` | 僵尸啃了路障一口 | `{ hp, maxHp, x, z }` |
| `barricadeBreak` | 路障被打碎 | `{}` |
| `barricadeRebuild` | 路障冷却结束重建 | `{}` |

新增事件时，两边都要改：`game.js` 里 emit，`visuals.js` 里 addEventListener。

`bossAttackDone` 是唯一的反向事件（画面层发、玩法层收）：Boss 的攻击节奏靠它同步，动画没演完就打不出下一拳。画面层拿不到模型 / 没有出拳动作时**不发**这条，玩法层会退回 `CONFIG.boss.attackFallback`（1.8 秒）的固定间隔，不会卡死。

## 画面层必须提供的函数

`game.js` 会调用这两个：

```
initVisuals(container, events)
  初始化场景。只调用一次。

syncScene(state, dt)
  每帧调用。dt 是距上一帧的秒数。
  负责把 state 画出来，并更新特效动画。
```

`ui.js` 必须提供：

```
initUI(state, actions)
  actions = { start, restart, revive, setPaused, returnToMenu }
  初始化界面。只调用一次。setPaused(true/false) 开关暂停，returnToMenu() 回到开始页。

updateUI(state)
  每帧调用。根据 state 更新士兵数、分数、显示哪一层界面。
```

## 几条规则

- 屏障在 `z < -21.5` 时不可被击中，哪怕子弹从它身上穿过
- 屏障从左边界一直铺到中间，但同一批在纵向上错开 8 个单位，不会排成一条直线
- 屏障分五类：绿色普通、红色负数、灰色陷阱、蓝色火力增援、紫色穿透器
- 普通屏障一发碎，加当前 `+N`，`+N` 随波次从 +1 升到 +5
- 红色负数屏障打到 0 以上会变绿，表示已经中和；打满上限或碰到士兵时结算
- 灰色屏障初始是负数，打到 0 就消失，最高只到 0，不会变成正数，也不给兵；碰到士兵照常扣兵
- 红色屏障保持一格，灰色屏障每 4 波变长一次，最多 3 格
- 红色屏障的数值上限随波次增长；灰色屏障上限固定为 0
- 火力增援屏障需要攒够命中（`30 + 6 × 波次`），攒够后枪位 +1，最多 8 个
- 穿透器需要攒够命中（`20 + 4 × 波次`），攒够后子弹有小概率不消耗，可以连续穿透最多 3 只
- 火力增援和穿透器没攒够就消失，不生效，碰到士兵也不生效
- 默认只有 1 个枪位，子弹从前排士兵的位置射出。总射速由士兵数决定，枪位变多时每个枪位变慢，总子弹数不变
- 枪位均匀分布在前排，最多 8 个
- 枪口有固定的小幅抖动，不扩散成扇形
- 士兵分三档：5 兵保安、20 兵正规军、50 兵特种兵；伤害 ×1.0 / 1.15 / 1.35，射击间隔下限 0.18 / 0.17 / 0.16
- 夜晚是第 4 到 6 波、10 到 12 波，僵尸移速 ×1.15
- 击杀只加分数，不加兵。大块头 +3 分、精英 +5 分，飘字显示“分数 +3 / +5”
- 子弹打中炸药桶会点燃 0.12 秒引信，随后爆炸，半径 3.2，伤害 `20 + 4 × 波次`
- 全部掉落物**只能用子弹打中才生效**，没有「走过去捡」这回事：炸药桶点火、补给箱碎裂结算奖励、武器箱换枪、空投补给的箱子开启 12 秒重武器。箱子类判定用扫掠区间（`hitCrate(x, z, prevZ)` / `hitPickup(x, z, prevZ)`），低帧率下一帧飞 1.4 格也不会穿箱；还在空中的箱子打不到
- 武器箱：开局 16 秒后第一个，之后每 26 秒一个、场上最多 1 个，打不中会在场上待 24 秒自己消失（否则会一直占着刷新位）；换来的枪持续 5 秒
- 空投补给（技能）也走 `state.pickups`：`kind: boost`，落在玩家正前方 3 格，打中才把 `weaponBoostUntil` 往后推 12 秒
- 射速按真实时间累计，一帧内可以补多枪（每枪位最多 6 发）：低帧率下高射速武器（机枪）不会被压成 1/fps 发
- 每张地图打 3 波，每个时代随机抽 3 张地图；三张打完（9 波）才进下一个时代，共 6 个时代
- 时代索引 = `min(5, floor((波次 - 1) / 9))`；在当前时代内的地图序号 = `floor(((波次 - 1) % 9) / 3)`
- 每换一张地图（第 4、7、10……波）刷一只 Boss；时代切换本身也落在地图切换的那一波
- 换时代只换配色和地图，不清空僵尸、子弹、屏障；士兵、分数、武器保留
- 地图从该时代的 `maps` 池里随机挑，尽量避开本局已经用过的
- 开局地图由 `?map=` 决定，默认 city，时代 0 直接用这张
- 开局时代由 `?era=` 决定，默认 0（中世纪）。从第 N 个时代开局时，起始波次为 `N × 9 + 1`，僵尸血量、Boss、卡池全部沿用现有按波次规则；初始兵力查 `CONFIG.era.startSoldiers`（5 / 20 / 40 / 65 / 90 / 120）。技能仍然从 0 开始
- 开局配置：中世纪什么都不给；二战/现代给 1 级穿透器 + 1 级火力增援；后现代给全部槽位 1 级；星际 2 级；终幕 3 级。穿透器 1/2/3 级 = 8%/12%/16% 继续穿透、最多 3/4/5 次；火力增援 N 级 = `1 + N` 个枪位；槽位等级同时作用于五个战斗槽和路障
- 中世纪/二战/现代开局路障不在场，抽到“路障”卡才解锁；解锁后抽到“路障升级”才升级。后现代及以后开局自带对应等级的路障
- 路障在前排偏右，左边界 x -0.4，z 0；范围内的僵尸停在 z≈-0.6 啃墙，范围外的正常通过
- 路障 5 级，宽度 4.2 / 5.2 / 6.2 / 7.1 / 8.0，右边界跟着长；满级右边界 7.6，盖住僵尸整条路
- 路障血量 240 / 300 / 360 / 420 / 480；反击伤害 0 / 8 / 16 / 26 / 40，每次啃咬结算一次
- 每 2 波结束抽一次卡，三选一；抽卡时全场慢放到 0.25 倍，10 秒倒计时，不选自动拿护甲或路障
- 卡池：路障解锁、路障升级、五个槽位各自的解锁卡 + 升级卡、火力强化、急行军、护甲、炸药桶强化、快速射击、火力增援
- 召唤槽的两张卡（`slotSummon` / `slotSummonUpgrade`）带 `state.era >= 3` 门槛，只在**后现代及以后**进入卡池；前三个时代抽不到，三选一的位置留给别的卡
- 六个槽位在画面层一视同仁：地基 / 光环 / 等级点永远可见，只有模型按 `state.slots` 决定出现。画面层不再自己判断时代（以前召唤有一条 `era < 3` 就把整块藏掉的规则，导致那个位置空无一物）
- 当前时代的 5 个一次性技能也会进卡池，抽到后存入 `state.skillBag`，不再立刻释放
- 进入终幕（`state.era === 5`）后改为按权重不放回抽卡：技能权重见 `FINALE_CARD_WEIGHTS`（审判 1、坍缩 1.5、献祭 2、重启 2、熵增 3），基础卡统一 2。其他时代仍是等概率
- 技能栏最多 4 种技能，同种最多 9 次；点左侧图标或按 1-4 使用，使用间隔 0.3 秒
- 技能栏满时再抽到新技能，自动替换次数最少的那个，按剩余次数 × 强度值折算成兵：1 次技能 12 兵/次，2 次技能 8 兵/次，3 次技能 5 兵/次
- 换时代时旧时代技能按同样公式折算成兵并清空
- 兵不够时使用献祭、没有可复刻技能时使用记忆植入，都不扣次数
- 四个可抽槽位默认锁定，抽到解锁卡生效；之后抽到对应升级卡升到 1-5 级；`state.slotLevels` 记录等级，0 表示未解锁，`state.slots` 仍然记录是否生效
- 召唤槽后现代（时代 3）起可以抽卡解锁，星际（时代 4）起保底自动补到 1 级；之后只能用升级卡往上升
- 槽位运行：攻城打最密的一群，炮弹飞行 0.5 秒落地时才结算伤害；近防打身边，支援回兵，指挥常驻加射速，召唤槽周期性制造友方僵尸；具体数值按等级和时代查 `docs/槽位升级数值.md`
- 召唤槽按等级出五种友军：盾尸、疾尸、爆尸、酸吐尸、巨尸。近战兵种冲向最近敌人互殴；爆尸贴身自爆，被打死也会炸；酸吐尸停在 4.5 距离外吐酸。预算按「小兵 1、巨尸 2」计算，巨尸同时最多 1 只
- 升级召唤槽会免费送一只新解锁兵种，之后第一只也优先出它；生物人军团和病毒转化的友军不占召唤预算
- 槽位卡描述显示「当前等级 → 下一等级」和下一级的关键数值
- 槽位和技能目前用简单几何体占位：攻城炮、近防炮塔、支援帐篷、指挥旗杆、召唤舱；炮弹走抛物线，近防拉曳光，范围技能从天上砸下来
- 一次性技能 30 个，按类型运行：aoe 范围伤害、airStrike 多点轰炸、barrage 持续洗地、napalmWall 火墙、rollingLog 滚木、knightCharge 骑士冲锋、tank 坦克支援、apc 装甲车、carrierDrones 舰载无人机、orbital 轨道光柱、weaponDrop 空投重武器、virusBomb 病毒转化、friendlyLegion 召唤友军、campfire 持续火区、slow 减速、freeze 原地停顿、buff 攻速、heal 回兵、pull 聚怪、warp 传送、execute 全场处决、sacrifice 百分比削血、reboot 不计分撤回、clear 清屏（暂无人使用）、memory 复刻上一个技能
- 箭雨是半径 4 的圆形范围（直径 8，等于屏幕横向宽度的一半），不带横排判定
- 空袭选场上最密的 3 个点，每颗炸弹 70 伤害、半径 2.2，三颗错开落地
- 炮火覆盖是半径 5 的大范围连续轰炸：3 秒 6 波，每波 25 伤害、半径 2.2，落点随机
- 燃烧弹在最密处生成宽 8、纵深 1.8 的火墙，持续 4 秒，墙内每秒 12 伤害并减速 40%
- 坦克支援从底部槽位后方（x=-5.5, z=16）出现，打 5 发范围炮（每发 60、半径 3.0、间隔 1.2 秒、落地延迟 0.32 秒），打完最后一发后多停留 4 秒再撤退。
  **可叠加**：`state.tankSupports` 是数组，再放一次会找右边第一个空位（间距 2.4）新增一辆，不覆盖前一辆；撤退中的也算占位
- 装甲车冲锋从下方慢速向上，撞击每只僵尸 90 伤害一次，每 0.35 秒对最近僵尸机枪 12 伤害
- 轨道轰炸从士兵这一侧数起，清掉最近的 2/3 僵尸（按数量取整，至少 1 只），更远的一批留在场上，击杀照常计分；清完后 1.5 秒内暂停刷怪；光柱只铺在被打掉的那一段，z 最多到 6.9，不穿过士兵阵型；一局只能获得并使用一次
- 舰载无人机群召唤 4 架大型无人机，持续一波（15 秒），每 0.45 秒对最近僵尸造成 20 点、半径 1.8 的小范围伤害
- 虫洞把全场僵尸一起送回出生点并取消追击
- 终焉审判是 `execute`：全场按血量挑目标，生命 ≤50% 直接处决并照常计分，其余受 20% 最大生命伤害，Boss 改吃 30% 最大生命。它不看位置也不看半径，和轨道轰炸（按距离挑最近 2/3）刻意分成两种挑法
- 献祭是 `sacrifice` 的新版：消耗 20 兵，把全场僵尸的生命上限与当前生命一起 ×0.5（Boss ×0.75），不致死也不直接计分；场上没僵尸或兵不够时直接失败、不扣次数
- 重启是 `reboot`：全场僵尸不计分移出（不走击杀结算，自爆也不会连锁），士兵回补到 `state.peakSoldiers × 0.8`，随后 3 秒不刷怪
- `skillCast` 事件在终幕三张牌上额外带 `executed` / `chipped` / `shaved` / `removed` 坐标数组，画面层按它们逐个点名播特效
- 时间膨胀/时间减速/熵增的减速作用于僵尸所有移动：前进、横移、贴线滑行、啃墙和远程攻击
- 空投补给改空投重武器：12 秒内子弹伤害 ×2、射速 ×1.5，`state.weaponBoost*` 控制
- 病毒炸弹在最密点周围投 2 枚，落地把半径 2.6 内最多 8 只僵尸转成友方，恢复 60% 最大血量并反冲
- 生物人军团瞬间在阵型前沿生成 20 名友方僵尸
- 滚木是纵向长 6 的移动实体，从屏幕左边随机纵向位置出现，整根保持在屏幕内，从左往右滚；伤害 = 当前波普通僵尸血量 × 1.25，秒普通不秒大块头，每只僵尸每根滚木只结算一次
- 骑士冲锋一次生成 3 个骑士，从屏幕下方右半边随机 x 出现，骑士横向最小间距 1.6，向上贯穿；每个骑士对每只僵尸只结算一次 50 伤害。碰撞判定横向半径 0.9、纵向厚度 1.25
- 篝火在最密点生成半径 7 的大火区，持续 5 秒。圆心每秒 18 伤害，按到圆心的距离线性衰减，边缘保留 30%；`state.campfireZones` 负责伤害结算，`visuals.js` 的 `spawnCampfireFx(x, z, duration, radius)` 负责范围圈、石圈、木柴、火苗、火星和暖光
- 炸药桶爆炸后的地面火区只留 2.2 秒，比篝火短，不长时间挡视线
- 电磁脉冲让全场僵尸原地停顿 2 秒：`state.freezeUntil` 之前僵尸不移动、不横移、不啃路障
- 熵增除了减速，还会按最大生命百分比持续掉血：`state.entropyUntil` / `state.entropyPct` 控制截止时间和每秒比例，`applyEntropyDot()` 结算且至少留 1 血（不致死、不计分）；减速由 `currentSlowMul()` 算，从 `slowMul` 起按 `entropyRamp` 每秒递减到 `entropyMinMul`
- 黑洞只吸 `pullRadius` 内的僵尸，持续 `duration` 秒逐步拉向最密点，被吸住的僵尸会暂停自己的移动；结束时中心 `radius` 内按最大生命扣 `damagePct`（Boss ×`bossPctMul`）。宇宙坍缩仍是瞬间拉完，再走 `collapseDamage()`：按**吸引前**的距离分档扣最大生命（中心 35%、外圈 15%，Boss ×0.5）
- 献祭要求士兵严格大于 20；记忆植入要有「上一次用过的可复刻技能」或技能栏里有还能加次数的技能，否则不能使用。使用条件不满足时不扣技能次数
- 技能的具体数值和边界见 `docs/技能说明.md`
- 槽位等级已接进代码，数值表见 `docs/槽位升级数值.md`
- 测试模式：主界面开关打开后 `state.testMode = true`，左侧面板可切时代、调槽位等级、放所有技能、刷/清僵尸；测试模式里僵尸不扣兵、不啃路障，炸药桶不生成；士兵子弹正常造成伤害；正常模式的左侧技能栏在测试模式隐藏
- `state.card` 记录抽卡状态，`state.upgrades` 记录永久加成，`state.timeScale` 控制慢放
- 槽位位置：攻城 (4.5, 15)、支援 (-4.5, 15)、指挥 (0, 15)、近防 (5.5, 4.5)、召唤 (-5.5, 4.5)；工事就是路障，位置在 `CONFIG.barricade`
- 路障 240 血，僵尸每次啃 6 点、间隔 0.9 秒；归零后进入 10 秒冷却，冷却结束满血重建
- 被路障挡住的僵尸不能隔着墙伤害士兵；路障不挡子弹；Boss 对路障造成 3 倍伤害
- 炸药桶初始 2 个、最多 3 个，单个刷新，全部只出现在右半边（x ≥ 0.4），左边留给屏障
- 炸药桶生成时从天而降，落地前不可被击中
- 每 12 秒尝试补一个，只补在右半边；满了或位置太近就跳过
- 僵尸不会越线：走到 `z = 8.4` 就停住，沿防线以 15 的速度滑向士兵，直到贴上
- 僵尸在 `z > 1` 且离士兵 6 以内开始主动拐弯，侧向速度 3.8，其余时间走直线
- 僵尸的接触判定用阵型半宽：`0.9 + min(0.6, 士兵数 × 0.04)`，人越多阵型越宽
- 僵尸到线滑行时会朝移动方向前倾，脚下有尘土，用来掩盖最后一段横移
- 僵尸分 5 种，`type` 0 到 4，数值和外观的约定见 `docs/僵尸类型.md`
- 僵尸出生时写入 `maxHp`；精英（type 3）和 Boss（type 10）显示头顶血条，普通僵尸不显示
- 僵尸贴上士兵时扣 `touchLoss`，不同种类不一样
- 僵尸基础移动速度 3.2，每波还会加快；离玩家超过 16 时按 1.9 倍蓄力跑步靠近，进入 8 以内放慢到 0.55 倍并开始缓慢吸附
- 僵尸进入后半段且离玩家 9 以内开始横向吸附，横向速度 2.6
- 僵尸之间有 0.6 的最小间距，靠太近会互相推开，避免叠成一坨
- 一局开始时士兵是 5 个，复活兵力是 `20 + 3 × 波次`
- 士兵最多同时显示 120 个，站成三角形队列，超出的只体现在 HUD 数字上

## 数值在哪改

全部在 `game.js` 顶部的 `CONFIG` 里。改完保存，Live Server 会自动刷新。

要点：

- `barrier.spawnInterval` 控制屏障压下来的密度
- `barrier.rowGap` 是同一批屏障的横向间隔
- `barrier.staggerRange` 是同一批屏障的纵向错开范围，调大更零散
- `barrier.negativeChanceBase` / `PerWave` / `Max` 控制负数屏障随时间变多的速度
- `barrier.greyChance` 是负数屏障里灰色陷阱的比例，默认 35%
- `barrier.negativeLengthEveryWaves` / `negativeLengthMax` 控制灰色屏障变长的速度
- `barrier.negativeGrowth` / `capGrowth` 控制红色屏障数值上限的增长；灰色屏障固定打到 0 消失
- `barrier.weaponChance` / `piercerChance` 是两种特殊屏障的出现概率，默认各 2%
- `barrier.weaponHitsBase` / `weaponHitsPerWave` 是火力增援的命中要求
- `barrier.piercerHitsBase` / `piercerHitsPerWave` 是穿透器的命中要求
- `weapon.maxLines` 是枪位上限，默认 8
- `weapon.jitterBase` 是枪口抖动
- `weapon.pierceChance` / `pierceMax` 是穿透概率和最大穿透次数
- `formation.spacing` / `rowGap` 是前排横向间距和排间距
- `formation.maxSoldiers` 是士兵的显示上限，默认 120
- `player.tiers` 是兵种阶级的伤害和射击间隔
- `zombie.nightSpeedMul` 是夜晚僵尸移速倍率
- `barrel.damageBase` / `damagePerWave` 是炸药桶爆炸伤害
- `barrel.spawnInterval` 是补桶间隔，默认 12 秒
- `barricade.*` 是路障的位置、血量、啃咬伤害、攻击间隔和重建冷却
- `CONFIG.era.count` / `everyWaves` / `mapsPerEra` 是时代数量、每张地图波数和每时代地图数
- `state.era` / `mapId` / `usedMaps` 记录当前时代、当前地图和本局用过的地图；`state.eraMaps` 是当前时代随机抽出的 3 张地图，`state.mapIndex` 是当前打到第几张；`state.startEra` / `startMap` 记录开局选择，重新开始时沿用
- `CONFIG.card.everyWaves` / `slowMo` / `duration` 是抽卡节奏、慢放倍率和选择时长
- `CONFIG.slots` 是五个槽位（含召唤）的坐标和 1-5 级倍率，工事位就是路障
- `CONFIG.era` 里是时代倍率、推荐等级和欠级折扣参数
- `state.slotLevels` 是五个槽位的等级（0 未解锁），`state.slots` 是对应的是否生效，`state.slotTimers` / `slowUntil` / `slowMul` / `buffUntil` / `buffMul` / `freezeUntil` / `entropyUntil` / `entropyDps` 是运行状态
- `state.testMode` 控制测试模式，测试面板由 `src/ui.js` 读取这个字段决定显示
- `SKILL_DEFS` 是 30 个一次性技能的定义，`SKILL_CHARGES` 是每张卡给几次，`castSkill(id)` 执行，`gainSkill(id)` 存进技能栏，`useSkill(id)` 消耗一次
- `upgrades.damage` / `moveSpeed` / `damageReduction` / `barrelDamage` / `fireRate` 是卡牌带来的永久加成
- `zombie.spawnInterval` 和 `intervalPerWave` 控制僵尸潮的强度
- `zombie.types` 是五种僵尸的倍率、碰兵伤害、权重和解锁波次，想看总表去 `docs/僵尸类型.md`
- `state.spawnCounts` 记录每种僵尸实际刷了多少只，调权重时用
- `zombie.turnSpeed` 是僵尸主动拐弯时的横向速度
- `zombie.lineSlideSpeed` 是僵尸到线后沿防线滑向士兵的速度，必须大于士兵移速，否则会僵持
- `zombie.touchBase`、`touchPerSoldier`、`touchMaxBonus` 控制阵型接触宽度
- `zombie.aggroStartZ` 和 `zombie.aggroRadius` 决定僵尸多近才开始横向吸附
- `zombie.chargeDistance` / `chargeSpeedMul` 控制远距离蓄力跑步；`absorbDistance` / `absorbSpeedMul` 控制近距离放慢吸附
- `zombie.separation` 是僵尸之间的最小间距

调试：浏览器控制台输入 `__state` 可以看实时状态（士兵、僵尸、子弹数量）。
