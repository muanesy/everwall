# 广告里的游戏

抖音 AI 实训营作品原型。把《向僵尸开炮》虚假广告里那种玩法真的做出来：竖屏、俯视角、2.5D 的生存射击小游戏。

## 怎么跑起来

1. 用 VS Code 打开这个文件夹
2. 安装 `Live Server` 插件（左侧扩展面板里搜）
3. 右键 `index.html`，选 `Open with Live Server`

浏览器会打开一个本地地址，改完代码保存会自动刷新。

注意：直接双击 `index.html` 打不开，一定要用 Live Server。3D 库需要通过本地服务器加载，这是浏览器的安全限制。

## 玩法

- 我方士兵在屏幕下方，左右移动，自动开火
- 屏幕左半边不断压下来一排排绿色 `+1` 屏障，子弹打中一次士兵 +1。屏障还在屏幕外时打不到
- 屏幕右半边是大量僵尸，越过防线会让士兵减员
- 士兵越多，射速越快、弹道覆盖越宽
- 士兵归零，游戏结束。可以点“看广告复活”回 20 个兵
- 分数就是打死的僵尸数

## 操作

- 键盘：← → 或 A / D 左右移动
- 手机：按住屏幕左右拖动
- 自动开火，不用按键

## 文件分工

| 文件 | 负责 | 作用 |
| --- | --- | --- |
| `index.html` | 甲 | 页面骨架，把各部分装起来，基本不用改 |
| `src/game.js` | 甲 | 玩法逻辑、数值、波次、碰撞 |

| `docs/` | 两人 | 设计文档和约定 |

## 技术栈

- Three.js（网页 3D 库，通过 CDN 加载）
- 原生 JavaScript，无构建步骤，不需要安装 Node.js
- 竖屏正交相机，固定俯视角
