# 广告里的游戏

抖音 AI 实训营作品原型。把《向僵尸开炮》虚假广告里那种玩法真的做出来：竖屏、俯视角、2.5D 的生存射击小游戏。

## 怎么跑起来

### 最快的方式

双击项目里的 `start-game.bat`，或者在桌面上双击“打开游戏”快捷方式。

它会自动起一个本地服务器并打开浏览器。那个黑色窗口不要关，关了游戏就停了。

电脑上需要装 Python（已经装了）。

### 用 VS Code 开发时

1. 用 VS Code 打开这个文件夹
2. 安装 `Live Server` 插件（左侧扩展面板里搜）
3. 右键 `index.html`，选 `Open with Live Server`

浏览器会打开一个本地地址，改完代码保存会自动刷新。

注意：直接双击 `index.html` 打不开，一定要通过本地服务器。3D 库需要通过服务器加载，这是浏览器的安全限制。

## 地图预览

默认是废墟街道。在地址后面加参数切换：

```
http://localhost:8765/?map=city
http://localhost:8765/?map=jungle
http://localhost:8765/?map=desert
http://localhost:8765/?map=moon
http://localhost:8765/?map=snow
http://localhost:8765/?map=lava
```

每张图的外观配置在 `src/visuals.js` 顶部的 `MAPS` 里，包括贴图、地面颜色、雾、灯光和背景物。里面的“机制建议”只是备注，真正的机制要写在 `game.js` 里。

## 玩法

- 我方士兵在屏幕下方，左右移动，自动开火，一次打出一束密集的子弹
- 屏幕左半边不断压下来一整排屏障，从左边界铺到中间
- 大部分屏障是 `+1`，一发子弹就碎，士兵 +1
- 少量屏障是负数（-10 到 -30）。打一发数值 +1，打满上限（10 到 30）或碰到士兵时，数值才生效
- 屏幕右半边是大量僵尸，会朝士兵靠拢。碰到士兵扣 1，越过防线扣 5
- 士兵越多，射速越快，一束里的子弹也越多
- 士兵归零，游戏结束。可以点“看广告复活”回 20 个兵
- 分数就是打死的僵尸数

## 操作

- 键盘：← → 或 A / D 左右移动
- 手机：按住屏幕左右拖动
- 自动开火，不用按键

## 文件分工

| 文件 | 负责 | 作用 |
| --- | --- | --- |
| `index.html` | 甲 | 页面骨架，把各部分装起来，基本不用改 |
| `src/game.js` | 甲 | 玩法逻辑、数值、波次、碰撞 |
| `src/visuals.js` | 乙 | 3D 场景、相机、模型、特效 |
| `src/ui.js` | 乙 | 血条、分数、开始页、结束页 |
| `src/styles.css` | 乙 | 界面样式 |
| `assets/` | 两人 | 图片、音效、模型 |
| `docs/` | 两人 | 设计文档和约定 |

## 技术栈

- Three.js（网页 3D 库，通过 CDN 加载）
- 原生 JavaScript，无构建步骤，不需要安装 Node.js
- 竖屏正交相机，固定俯视角
