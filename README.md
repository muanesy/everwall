# 广告里的游戏

抖音 AI 实训营作品原型。把《向僵尸开炮》虚假广告里那种玩法真的做出来：竖屏、俯视角、2.5D 的生存射击小游戏。

## 怎么跑起来

### 最快的方式

双击项目里的 `start-game.bat`，或者在桌面上双击“打开游戏”快捷方式。

它会自动起一个本地服务器并打开浏览器。那个黑色窗口不要关，关了游戏就停了。

这个服务器会给所有文件发禁止缓存的响应头，所以改完代码普通刷新就能看到最新版本，不用无痕窗口，也不用强制刷新。

### 怎么确认自己看的是不是最新版

**开始页标题下面那行小字就是版本标记**，格式是 `#提交号 · 提交时间 · 26 地图`：

- 带 `*` 号 = 工作区还有没提交的改动，你看到的就是磁盘上的最新代码
- 不带 `*` = 工作区干净，显示的就是那个提交的内容
- 如果显示成 `v2026-11-02 · 26 地图（离线兜底标记）`，说明没连上本地服务器（断网 / 用别的工具打开），这时看不到提交号

**改了东西但版本号纹丝不动、也没有 `*`，那是浏览器还停在旧页面，不是代码没生效。** 这个标记就是为了把这两种情况分开，别再去猜是不是启动器坏了。

配套的两条：

- `start-game.bat` 每次都用带随机时间戳的网址打开（`?t=xxxx`），浏览器不会复用之前那张旧标签页
- 黑色窗口如果说「8765 端口已经有服务器在跑了」，说明上一次开的窗口还留着，关掉它再双击

电脑上需要装 Python（已经装了）。第一次运行如果弹出防火墙提示，允许即可，手机测试需要它。

### 用 VS Code 开发时

1. 用 VS Code 打开这个文件夹
2. 安装 `Live Server` 插件（左侧扩展面板里搜）
3. 右键 `index.html`，选 `Open with Live Server`

浏览器会打开一个本地地址，改完代码保存会自动刷新。

注意：直接双击 `index.html` 打不开，一定要通过本地服务器。3D 库需要通过服务器加载，这是浏览器的安全限制。

## 测试模式

开始页有一个「测试模式」开关。打开后点「开始测试」进游戏，屏幕左侧会出现面板：

- 6 个时代随便切
- 6 个槽位可以解锁、升级到 5 级，面板上直接显示当前数值
- 30 个一次性技能都能直接点
- 可以刷 20 只僵尸或清空场上僵尸

测试模式里士兵不会掉血，僵尸也啃不动路障；炸药桶不生成。士兵子弹、技能、槽位和路障反击都正常造成伤害。

也可以在地址后面加 `?test=1`，开始页会自动打开测试模式。

## 地图

默认是废墟街道。开始页有一排地形按钮，点一下就会切换。

也可以直接在地址后面加参数：

```
http://localhost:8765/?map=city
http://localhost:8765/?map=jungle
http://localhost:8765/?map=desert
http://localhost:8765/?map=moon
http://localhost:8765/?map=snow
http://localhost:8765/?map=lava
```

每张图的外观配置在 `src/visuals.js` 顶部的 `MAPS` 里，包括贴图、地面颜色、雾、灯光和背景物。每张图想做的玩法差异和进度，看 `docs/地图机制.md`。

## 玩法

- 我方士兵在屏幕下方站成前排最宽的阵型，左右移动，自动开火，默认一个枪位
- 屏幕左半边不断压下来一整排屏障，分五种：
  - 绿色普通屏障：一发碎，加 `+N`，N 随波次从 +1 升到 +5
  - 红色负数屏障：打一发数值 +1，打到 0 以上会变绿；打满或碰到士兵时结算
  - 灰色陷阱屏障：初始是负数，打到 0 就消失，不会变成正数，也不给兵；碰到士兵照常扣兵
  - 蓝色火力增援：攒够命中后枪位 +1，最多 8 个
  - 紫色穿透器：攒够命中后子弹有小概率穿透僵尸，可以连续穿透最多 3 只
- 火力增援和穿透器没攒够命中就消失，错过不生效
- 屏幕右半边是大量僵尸，分五种：普通、大块头、快鬼、精英、女僵尸，血量和速度各不相同
- 僵尸会朝士兵靠拢，贴上时按种类扣兵。具体数值看 `docs/僵尸类型.md`
- 士兵越多，总射速越快；枪位变多时每个枪位变慢，总子弹数不变
- 士兵归零，游戏结束。复活兵力随波次增长
- 分数按僵尸类型给，越硬的怪分数越高
- 一次性技能卡抽到后存入左侧技能栏，按技能强度给 1-3 次使用机会；技能栏最多 4 种，满了自动替换次数最少的，并把被替换技能折算成兵
- 后现代起自动解锁第六个召唤槽，周期性制造绿色友方僵尸，冲向敌人近战对冲

## 操作

- 键盘：← → 或 A / D 左右移动
- 键盘：数字键 1-4 使用左侧技能栏
- 手机：按住屏幕左右拖动，点左侧图标放技能
- 自动开火，不用按键

## 技术栈

- Three.js（网页 3D 库，通过 CDN 加载）
- 原生 JavaScript，无构建步骤，不需要安装 Node.js
- 竖屏正交相机，固定俯视角
